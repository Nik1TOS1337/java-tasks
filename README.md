# Конкурс грантов

Учебный сервер на Java 17. Проект использует Maven, Gson и JUnit 5. Все данные хранятся в оперативной памяти. После остановки программы они теряются. Работа проверяется через тесты. Консольный ввод и HTTP не используются.

## Проверка проекта

Для запуска тестов нужны JDK 17 и Maven. Команда выполняется из папки проекта.

```text
mvn test
```

## Устройство проекта

Классы находятся в пакете `academy.tochkavhoda.competition`. Пакет `server` принимает запросы. Пакет `service` проверяет данные и выполняет операции. Интерфейс `dao` и его реализация `daoimpl` передают данные в `database`. Класс `DataBase` создан в одном экземпляре. Пакет `model` содержит данные конкурса. Классы запросов и ответов находятся в `dto.request` и `dto.response`.

## Настройка конкурса

При создании `Server` передаются общий фонд, порог средней оценки и срок завершения конкурса. Фонд и порог имеют тип `BigDecimal`. Срок имеет тип `Instant`. Фонд не может быть отрицательным. В суммах допускаются копейки. Порог находится в пределах от 0 до 5.

Для тестов есть конструктор с параметром `Clock`. Он позволяет проверить срок без ожидания. Все экземпляры сервера работают с общей базой и одинаковыми настройками. Метод `clear()` очищает данные и итоги для независимого запуска тестов. Настройки он сохраняет. Этот метод не является запросом пользователя.

## Запросы

Методы `registerParticipant`, `registerExpert` и `login` принимают JSON. Остальные методы принимают токен. Если нужны данные запроса, JSON передаётся вторым параметром.

Регистрация участника использует поля `firstName`, `lastName`, `company`, `login`, `password`. Регистрация эксперта использует поля `firstName`, `lastName`, `directions`, `login`, `password`. Для входа нужны `login` и `password`. Логин содержит от 3 до 64 знаков. Разрешены латинские буквы, цифры, точка, знак подчёркивания и знак `@`. Пароль содержит от 6 до 128 знаков. Пароли хранятся в виде хешей PBKDF2 с солью.

Метод `logout` завершает сеанс. Метод `deleteAccount` удаляет аккаунт и связанные с ним заявки или оценки. При повторном входе создаётся новый токен. Предыдущий токен перестаёт действовать. Данные регистрации не меняются.

Метод `addApplication` принимает поля `title`, `description`, `directions`, `amount`. Метод `addApplications` принимает поле `applications` со списком заявок. При ошибке в одной из них весь запрос отклоняется. Ответ содержит список `applicationIds`. Метод `cancelApplication` принимает `applicationId`. Метод `getMyApplications` возвращает заявки участника.

Метод `getApplications` принимает список `directions` и возвращает заявки по выбранным направлениям эксперта. Метод `getRatedApplications` возвращает заявки с его оценками. Метод `setVote` принимает `applicationId` и целое число `score` от 1 до 5. Повторный вызов заменяет прежнюю оценку. Метод `deleteVote` принимает `applicationId` и удаляет оценку эксперта.

Метод `getResults` возвращает итоговый список `applications` и остаток `remainingFund`. Каждый элемент списка содержит заявку `application` и признак выдачи гранта `funded`. Средняя оценка выводится с точностью до шести знаков после запятой. При сравнении оценок округление не используется.

Успешный ответ имеет код 200. Регистрация, удаление и другие операции без данных возвращают `{}`. Вход возвращает поле `token`. Ошибка имеет код 400 и поле `error` с её описанием.

## Принятые правила

Направления и логины сравниваются без учёта регистра. Названия фирм и имена также сравниваются без учёта регистра и лишних пробелов. Фирма определяется по названию. Эксперт определяется по фамилии и имени. По этим данным нельзя надёжно отличить полных тёзок. В задании нет другого признака личности.

Заявка относится к выбранным направлениям, если совпало хотя бы одно из них. Эксперт может оценить заявку при совпадении хотя бы одного своего направления. Заявки без оценок имеют среднюю оценку 0 и не получают грант.

Начиная с указанного срока нельзя подавать и отменять заявки, ставить, менять или удалять оценки. Итоги рассчитываются при первом обращении к серверу после наступления срока. До этого момента изменить конкурс после срока также нельзя. Итоги сохраняются и больше не пересчитываются. Удаление аккаунта остаётся доступным и не меняет сохранённые итоги.

При равной средней оценке выше стоит заявка с меньшей суммой. При полном равенстве порядок выбирается случайно один раз. Заявка получает грант только при средней оценке строго выше порога и достаточном остатке фонда. Дорогая заявка пропускается. Оставшиеся заявки продолжают рассматриваться.
